## Recommended approach for deployment

### For softwood (spruce-like) logs
- **Best quality**: OBB-augmented anchor propagation v2.2 (ellipse seeds + 
  anatomical filters). Needs ~20 hand-annotated anchor frames per log.
- **Zero annotation**: OBB-only propagation works well. No anchors needed.
  Quality slightly lower but usable as first-pass pre-annotation.

### For hardwood (oak-like) logs
- **Must have anchors** (~20 per log) + use SAM2 point-seeded propagation
  (v2.3 / auto_3_obb_aug_points_v1 recipe). Without anchors, shapes
  degrade to ellipses.

### Universal recipe (one pipeline for any wood type)
- SAM2 point-seeded augmented propagation (v2.3 recipe):
  - Anchor GT at annotated frames (knots only is enough).
  - YOLO-OBB → SAM2 image predictor (box + 5 pos along axis + 4 neg at
    OBB edges) → per-frame knot mask → seed into MedSAM2 video propagator.
  - Post-filters: min 150px, pith exclusion 25px, eccentricity >0.7,
    solidity >0.85, fill_holes.
  - Pith: YOLO bbox centroid at conf=0.10.
  - Wood: threshold(t=30) ∪ propagated wood.

## Annotator workflow discussion points

### Payment model
- **Pay per annotated frame, not per hour.** Incentivises speed without
  sacrificing quality (quality is reviewable; time is not).
- Suggested metric: **frames per batch** with quality spot-checks (random
  10% reviewed by Rostislav or Mara).
- Bonus for clean batches (no rework needed after review).

### Anchor annotation requirements
- Each anchor frame needs: **knots only** (bitmaps). Wood and pith can be
  computed automatically.
- Target: **~20 anchors per log**, roughly every 10-15 frames. Denser in
  knot-heavy regions, sparser in clean wood.
- Time per anchor: ~2-5 minutes if using shortcuts.

### Keyboard shortcuts — CRITICAL for productivity

Supervisely shortcuts that annotators MUST learn:

| shortcut | action | why it matters |
|---|---|---|
| **S** | Smart Tool (SAM-based segment) | Main tool for creating knot masks. Click inside the knot, SAM segments it. |
| **B** | Brush | For refining mask edges after smart-tool. |
| **E** | Eraser | Remove over-segmented parts. |
| **Shift+click** | Add to selection (Smart Tool) | Extend a mask to cover the full knot if smart-tool missed part. |
| **Ctrl+Z** | Undo | Essential for quick correction. |
| **Space** | Confirm/finish current object | Saves the current annotation and moves to next. |
| **D** / **A** | Next / previous image | Navigate between frames without using mouse. |
| **Ctrl+C / Ctrl+V** | Copy / paste annotation | Reuse annotation from previous frame (then adjust with brush). Huge time saver for similar consecutive frames. |
| **H** | Hide/show annotations | Toggle overlay to see the raw image. |
| **1-9** | Select class by number | Switch between Knot/Wood/Pith without menu. |

**Recommendation**: create a 1-page cheat sheet PDF with these shortcuts and
require annotators to have it printed next to their screen. First 30 minutes
of onboarding = practice with shortcuts on a sample log.

### Annotator instructions (draft)

1. Open the assigned dataset in Supervisely.
2. Navigate to the assigned anchor frame (every ~15th frame).
3. For each visible knot:
   a. Press **S** (Smart Tool).
   b. Click inside the knot. SAM will segment it.
   c. If the mask is too small: **Shift+click** on missed parts.
   d. If the mask bleeds into wood: press **B** (brush), then **E** (eraser)
      to trim.
   e. Press **Space** to confirm.
4. When all knots on the frame are done, press **D** to go to next frame.
5. Skip frames that are not assigned anchors (the pipeline fills them in).
6. Do NOT annotate wood or pith — the pipeline handles those automatically.

### Quality expectations
- Every visible knot should be annotated (recall > precision for anchors,
  since the pipeline's filters handle FPs).
- Masks should roughly follow the knot boundary (±5 px is fine; brush
  perfection is not needed — SAM will refine during propagation).
- Missed knots on anchor frames = missed knots on all nearby frames.
  Completeness matters more than pixel-perfect boundaries.
